# Daily Notes

One note per day of what got done, what is still open and what was decided, across every AI session. Notes sit in month folders named NN - Month YYYY (for example 11 - November 2026). The assistant writes these; you just talk. A daily note is a log, never the record: every answer or decision also gets saved to its own note.

**Keeping this list current:** whenever a note in this folder is created, renamed, moved or changed in a meaningful way, the assistant updates the list below (one line per note) in the same pass. When a note moves to another folder, it comes off this list and goes onto that folder's list.
